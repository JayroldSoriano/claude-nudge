Claude is waiting.
Nudge makes sure you know.

A pixel mascot waves at you in Chrome when Claude Code has a question, needs permission, or is done. Ignore it and it gets annoyed.

npx nudge-for-claude-code setup
Add to Chrome View on GitHub Pro: notify me

Free and open source. Requires Node 18+ and Chrome 116+. Nothing leaves your machine.

How it works

Claude Code hook→curl→relay on 127.0.0.1→WebSocket→extension→mascot on your active tab

Claude Code's Stop, Notification, and AskUserQuestion hooks post to a zero-dependency Node relay on localhost. The relay pushes to the extension, which draws Nudge on whatever tab you're looking at, with the actual question and its options in a speech bubble. The mascot follows you across tabs and windows. Answering in the terminal dismisses it everywhere.

The relay binds to 127.0.0.1 and rejects any web-page origin. The content script lives in a closed shadow root and never reads the page. No accounts, no analytics, no servers.

The longer you ignore it, the harder it tries

Level 0 · 0sCorner wavePops into the corner with the question. Polite.
Level 1 · 15sWalks to centerWaves harder. The hint counts how long Claude has been waiting.
Level 2 · 30sGrows, gets annoyed1.8x bigger, flat eyes, foot tapping. The bubble turns red and shakes.
Level 3 · 60sAlarm, roamsA short alarm, then it hops along the bottom of the page.

Only questions and permissions escalate, because that's when Claude is blocked. "Done" nudges stay quiet and auto-dismiss. The clock runs only while Chrome is focused. Pick Gentle or Full Chaos, or turn it off. There's a snooze. We're not monsters.

Install

npx nudge-for-claude-code setup

That installs the hooks into ~/.claude/settings.json, starts the relay (and keeps it running at login), and tells you where to load the extension. Then restart Claude Code and run npx nudge-for-claude-code test.

Prefer to do it by hand? Everything is in the README.
