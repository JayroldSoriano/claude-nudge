Privacy Policy

Nudge (the Chrome extension and its local relay). Last updated 2026-10-30.

Summary

Everything stays on your computer. The extension has no accounts, no analytics, no remote servers, and sends nothing over the internet.

What the extension does

Claude Code hooks send small JSON payloads (the event name, your project folder name, and the text of Claude's question, permission request, or final message) to a relay process running on your machine at 127.0.0.1. The relay forwards them over a local WebSocket to the extension, which draws a mascot and a speech bubble on the tab you are viewing.

Data collected

None. The extension does not collect, transmit, sell, or share any personal data, browsing history, or page content.

Data stored

  • Your settings (which nudges to show, escalation mode, timings, relay port) in Chrome's extension storage.
  • The last ten nudge events (title, project name, message text) in Chrome's local extension storage, shown in the popup. Cleared when you remove the extension.
  • The relay keeps the last 25 events in memory only; nothing is written to disk except an optional log file you enable yourself.

Page content

The content script renders the mascot inside a closed shadow root. It does not read, modify, or transmit the content of any web page.

Permissions

  • <all_urls> and scripting: draw the mascot on whichever tab is active.
  • storage: settings and the recent-events list.
  • alarms: keep the local relay connection alive.
  • notifications: fallback system notification on pages where content scripts cannot run.

Network

The only network connection is to 127.0.0.1 on your own machine. The relay rejects connections from web pages and accepts only the extension or local command-line tools.

Third parties

None. The extension does not use third-party services, SDKs, or trackers. Claude Code is a product of Anthropic; this extension is an independent project and is not affiliated with or endorsed by Anthropic.
